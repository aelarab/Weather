# 🌤️ Weather App – SwiftUI (MVVM)

## 📱 Overview
**Weather** is a modern iOS application built with **SwiftUI** using the **MVVM architecture pattern**.  
It fetches real-time weather data based on the user’s **current location** using the [WeatherAPI](https://www.weatherapi.com/).  
The app dynamically changes its background and text colors to match the **day/night theme**, creating a smooth and elegant experience.

---

## ✨ Features
- 🌎 **Automatic location detection** (CoreLocation)
- ☀️ **Live weather updates** (current temperature, humidity, visibility, pressure)
- 📅 **3-day forecast** with condition icons
- 🕒 **Detailed hourly forecast** for each day
- 🌓 **Dynamic backgrounds** for day & night modes
- 🎨 **Adaptive text color** (dark in morning, white at night)
- ⚡ **MVVM architecture** for clean and scalable structure

---

## 🧱 Architecture
This project follows the **MVVM (Model–View–ViewModel)** pattern to ensure a clean separation between business logic and UI layers.
